# `geometor/.github`

Organization-wide GitHub profile and shared visual assets for [**GEOMETOR**](https://github.com/geometor) (*Exploring the architecture of all that is*).

## Contents

- [`profile/README.md`](profile/README.md): Public landing page rendered on [`https://github.com/geometor`](https://github.com/geometor), showcasing GEOMETOR's Key Projects and linking to the complete Books & Catalogs directory on [`geometor.com/books/`](https://geometor.com/books/).
- [`profile/vesica-phi-dark.svg`](profile/vesica-phi-dark.svg) & [`profile/vesica-phi-light.svg`](profile/vesica-phi-light.svg): Exact symbolic `SymPy` dark/light vector banners stepping from two starting points through the Vesica Piscis and Equidistant Poles to George Odom's Golden Section ($\phi = \frac{1 + \sqrt{5}}{2}$), generated by `geometor.com/scripts/build_hero_svg.py`.
