exploring the architecture of all that is
-----------------------------------------

.. image:: ./root3-harmonics-banner.png
   :align: center
   :alt: GEOMETOR Harmonics

**GEOMETOR** is an open-source initiative for exploring geometry, nature, and logic through symbolic modeling. We develop tools to create, visualize, and analyze geometric constructions, with a focus on discovering fundamental patterns and advancing machine reasoning.

Core Tools
----------

.. image:: ./geom-banner.png
   :align: center
   :alt: GEOMETOR Explorer

- `explorer <https://github.com/geometor/explorer>`_: **Interactive Visualization**. The primary interface for creating and analyzing geometric models.
- `model <https://github.com/geometor/model>`_: **Symbolic Engine**. Defines points, lines, and circles using exact algebraic expressions.
- `divine <https://github.com/geometor/divine>`_: **Analysis**. Uncovers golden sections and harmonic ranges within constructions.

Research & Exploration
----------------------

.. image:: ./arc-banner.png
   :align: center
   :alt: ARC Prize

- `elements <https://github.com/geometor/elements>`_: **Euclid's Elements**. A digital reconstruction of the classic text, modeling the logical dependencies of geometry.
- `seer <https://github.com/geometor/seer>`_: **Abstract Reasoning**. An AI framework for solving reasoning challenges like the ARC prize.
- `phyllotaxis <https://github.com/geometor/phyllotaxis>`_: **Patterns in Nature**. Investigating geometric growth patterns in plants.
